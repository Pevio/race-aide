# Race Aide

An app to track runners in a race.

Some races spend big bucks on GPS trackers. If you don't have the budget for that, just use Race Aide! You enter in the runners with their bib numbers, and assign your assistants to the checkpoints around the course, who will record when each runner passes the checkpoint. You'll see live results and standings, with time at each checkpoint for each runner. If a runner goes missing, you'll know what checkpoint they were last at, and if a runner skips a checkpoint, you'll know immediately.

## Back End

Express.js in Javacsript, with API actions for creating and modifying a race, runners, checkpoints, and run times.

## Front End

React in JavaScript, with public pages to see race details and results, and authenticated pages to edit details and enter runner information and times.
